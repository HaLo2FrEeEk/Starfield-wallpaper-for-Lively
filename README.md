# Starfield (wallpaper for Lively)
You'll need [Lively Wallpaper by rocksdanister](https://github.com/rocksdanister/lively) installed.

Particles (or stars) flowing smoothly and endlessly in a Perlin Noise field. Very customizable.

![](Starfield/thumb.gif)

[Download the ZIP file](https://github.com/HaLo2FrEeEk/Starfield-wallpaper-for-Lively/releases), drop it into the Lively Wallpaper app.
